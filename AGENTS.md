# Project code guidelines

Apply these principles to all code in this repository:

- Favor readability over compactness. Use descriptive names, clear control flow,
  and enough space and structure for a reader to understand the code easily.
- Follow the clean code principles described in Robert C. Martin's *Clean Code:
  A Handbook of Agile Software Craftsmanship*. Keep functions focused, avoid
  unnecessary duplication, and make intent explicit without overengineering.
- Preserve existing behavior and visual design when refactoring, and run the
  relevant checks described in CONTRIBUTING.md.
